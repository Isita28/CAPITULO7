Corrección de errores

Errores comunes: punto y coma tras if, contador sin inicializar, falta de actualización del contador y ciclo infinito.

Usa if (edad >= 65) { ... } else { ... }.

Inicializa el contador, por ejemplo let x=1;.

Actualiza el contador dentro del ciclo con x++;.

Garantiza que la condición de while se vuelva falsa.
